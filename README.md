# BREWLAB Coffee Shop Website

This is a simple four-page student project made with HTML, CSS and JavaScript.

## Open the website

Open `index.html` in a browser. Use the navigation links to visit Home, About Us, Menu and Contact.

## Assignment features

- Introduction, company background, past and current project experience, and services.
- Cafe photos and a BREWLAB logo.
- Menu tables and downloadable PDF and CSV menus.
- Contact form with text, email, telephone, date, time, password, select, radio, checkbox and message fields.
- External CSS with tablet and mobile media queries.
- Simple JavaScript form message.
- External Gigi Coffee link and internal page/image links.

Menu prices and project background are examples. The form does not send or store information. Cafe photos need an internet connection.
